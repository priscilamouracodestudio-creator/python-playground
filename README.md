# 🐍 Python Playground & Algorithms

Repositório centralizado para o estudo de algoritmos, lógica de programação e estruturas de dados em Python. Aqui organizo desde os fundamentos essenciais até pequenos jogos interativos baseados em terminal (CLI).

---

## 🚀 Projetos em Destaque

### 🦁 `animalguess`
Jogo interativo de adivinhação de animais que utiliza inteligência lógica básica. O grande diferencial é a **persistência de dados**: o jogo aprende novos animais e características dinamicamente e os salva estruturadamente em um arquivo `animal_data.json`, tornando cada partida única.

### 🌍 `quizgeography`
Um quiz CLI completo sobre geografia mundial. Lê perguntas estruturadas de um banco de dados simulado em JSON, avalia as respostas do usuário e calcula a pontuação em tempo real.

---

## 📂 Estrutura do Repositório

Com base na arquitetura modular do projeto, os scripts estão divididos assim:

* **`animalguess/`**: Jogo de adivinhação autônomo com leitura/escrita em JSON.
* **`quizgeography/`**: Aplicação de perguntas e respostas com base de dados acoplada.
* **`jogodavelha/`**: O clássico *Tic-Tac-Toe* construído sobre matrizes bidimensionais e lógica de turnos limpa.
* **`games-cli/`**: Coleção de minijogos de terminal (como `guessthecolor` e mecânicas de adivinhação).
* **`fundamental-exercises/`**: Scripts dedicados a algoritmos puros, loops, manipulação de arrays e estruturas condicionais acadêmicas.
